# IRON BLADE — лендинг барбершопу

Адаптивний односторінковий сайт барбершопу. Чиста статика: HTML + CSS + JavaScript,
без збірки, фреймворків і залежностей.

## Що всередині

| Файл | Призначення |
|---|---|
| `index.html` | Розмітка всіх секцій |
| `style.css` | Стилі, темна тема, адаптивність |
| `script.js` | Перемикач мови, бургер-меню, форма, анімації |

**Можливості:**

- Секції: hero, про нас, послуги, майстри, відгуки, форма запису, футер
- Дві мови — українська (за замовчуванням) і англійська, вибір зберігається в `localStorage`
- Ціни у гривнях
- Адаптив: мобільний (375px), планшет (768px), десктоп (1440px); на мобільному — бургер-меню
- Плавний скрол і поява карток через `IntersectionObserver` (без бібліотек)
- Форма запису — JS-заглушка без бекенду

## Локальний запуск

Достатньо відкрити `index.html` у браузері подвійним кліком.

Або підняти локальний сервер (коректніше — так вантажаться шрифти й фото):

```bash
python -m http.server 8123
```

Далі відкрити <http://localhost:8123>.

## Деплой — сайт працює 24/7

Сайт статичний, тому хоститься безкоштовно на будь-якій з платформ нижче.
Після налаштування кожен `git push` у `main` автоматично оновлює сайт.

### Варіант 1. Cloudflare Pages (рекомендую)

1. <https://dash.cloudflare.com> → **Workers & Pages** → **Create** → **Pages** →
   **Connect to Git**
2. Обрати цей репозиторій
3. Налаштування збірки:
   - **Framework preset:** `None`
   - **Build command:** залишити порожнім
   - **Build output directory:** `/`
4. **Save and Deploy**

Через ~30 секунд сайт доступний за адресою `*.pages.dev` з безкоштовним HTTPS.

### Варіант 2. Netlify

1. <https://app.netlify.com> → **Add new site** → **Import an existing project**
2. Обрати репозиторій — решту Netlify візьме з `netlify.toml`

### Варіант 3. GitHub Pages

Workflow уже налаштований у `.github/workflows/deploy-pages.yml`.
Треба лише один раз увімкнути Pages:

**Settings** → **Pages** → **Source: GitHub Actions**

Далі кожен push у `main` публікує сайт на `https://<user>.github.io/<repo>/`.

### Власний домен

На будь-якій із платформ: додати домен у налаштуваннях проєкту й прописати
у реєстратора DNS-записи, які покаже платформа. HTTPS-сертифікат
випускається автоматично.

## Фото

Зображення підключені за прямими посиланнями на [Unsplash](https://unsplash.com),
тож потрібен інтернет. Під кожним фото лишається текстова заглушка —
якщо картинка не завантажиться, верстка не зламається.

Щоб зробити сайт повністю автономним — скачати фото в теку `images/`
і замінити URL у `index.html` та `style.css` на локальні шляхи.
